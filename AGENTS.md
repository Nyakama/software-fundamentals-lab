# Agent Guidance

## Repository Scope and Content

- Work only inside this repository.
- Do not copy substantial passages from books.
- Do not upload book PDFs, answer keys, or copyrighted exercises.
- Do not invent quotations, page references, completed study progress, results,
  or achievements.
- Use fictional demonstration data only.
- Do not include client code, client names, credentials, private URLs, private
  assets, or material from private repositories.

## Development Practices

- Prefer TypeScript for future coding exercises and the practice project.
- Add tests whenever behaviour is introduced or changed.
- Do not refactor existing behaviour without tests.
- Run formatting, linting, type checking, and tests once those tools exist.
- Use focused branches and pull requests.
- Never merge without explicit approval.
