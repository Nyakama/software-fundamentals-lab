# Software Fundamentals Lab

Software Fundamentals Lab is a public learning and practice portfolio focused on
practical software development, testing, refactoring, and working with legacy
code. It provides an organised place for original learning notes, focused coding
exercises, and a small practice project.

The repository is intended to demonstrate careful, incremental learning rather
than completed study progress or professional achievements. Examples use
fictional, sanitised data and exclude confidential or copyrighted material.

## Repository Structure

- `docs/` contains original reading notes, chapter reviews, concept references,
  book summaries, and learning-journal entries.
- `exercises/` contains focused TypeScript practice covering naming, functions,
  defensive programming, testing, refactoring, and legacy code.
- `practice-project/` provides space for a cohesive TypeScript project and its
  automated tests.
- `.github/workflows/` is reserved for future repository automation such as
  formatting, linting, type checking, and test checks.

Each leaf directory includes a README that defines its scope and gives examples
of suitable future files.

## Working Principles

- Organise new material under the directory that matches its purpose.
- Practise one concept at a time through focused exercises.
- Prefer small, understandable changes on focused branches.
- Add tests whenever behaviour is introduced or changed.
- Refactor existing behaviour only when tests provide suitable protection.
- Keep all examples fictional and sanitised.
- Exclude credentials, private URLs, client material, private repository
  content, and substantial copyrighted passages.
- Run formatting, linting, type checking, and tests once those tools are
  available.

See `AGENTS.md` for the boundaries that apply to automated contributors.
